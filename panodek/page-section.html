The problem

A video wall used to mean 32 drags.

Stream Deck plays a GIF on each key, but it has no way to place a whole set at once. So you cut one clip into pieces, export every piece, and drag them into the app one key at a time. Change your mind and you start over.

How it works

01

Drop a clip on the deck

Drag in a video, GIF or photo. It fills every key, cropped to fit and never stretched.

02

Where you drop is how it splits

Drop on a half, a quarter, a row, a column or one key. The keys light up before you let go, and each block plays its own clip.

03

Frames and colors

Give each block a border and a color so a busy deck stays easy to read.

04

Grab a frame for the touch strip

One button takes a still from your clip and lines it up so the picture carries on under the keys.

05

Put actions on top

Hotkeys, apps, pages, multi actions and your plugins, each with an icon over the video.

06

One click to your Stream Deck

PanoDek builds the profile and hands it to Stream Deck. No dragging GIFs into place.

What do I need?

A Mac (or a Windows PC for the beta), a supported Stream Deck, and Elgato's free Stream Deck app. PanoDek builds the profile and Stream Deck loads it.

Does it change my existing profiles?

No. Each install adds a new profile. Your other profiles are left alone.

What can I use as a clip?

Videos (MP4, MOV), GIFs and still images. Stream Deck plays animation on keys; the touch strip shows a still.

Is there a Windows version?

Yes, as a beta. It has had far less testing than the Mac version, so expect rough edges.
